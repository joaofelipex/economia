# Como contribuir

O objetivo do projeto é manter material de economia, finanças e Python **aberto, gratuito e de boa qualidade**.
Toda ajuda é bem-vinda: correção de erro, exemplo novo, exercício, tradução, revisão de fórmulas e dados.

## Formas de ajudar
- **Reportar erro** (conta errada, fórmula, saída desatualizada, typo): abra uma *issue* dizendo arquivo, trecho e o que seria o correto.
- **Propor melhoria**: abra uma *issue* antes de mudanças grandes, para alinharmos o escopo.
- **Enviar alteração**: faça um *fork*, uma branch por assunto e abra um *pull request* pequeno e focado.

## Regras de conteúdo
- A fonte é o arquivo `.typ` (Typst). Compile com `typst compile arquivo.typ` e confira se o PDF gera sem erro.
- Todo código deve rodar. Se o texto mostra uma saída, ela deve ser a saída real do código mostrado.
- Cite a fonte de dados e fórmulas. Prefira dados abertos (BCB, IBGE, Ipeadata) e não inclua dados de terceiros sem licença compatível.
- Nos capítulos de exercícios, não inclua gabarito junto do enunciado.
- Não inclua informações pessoais, material confidencial de empregadores ou conteúdo copiado de livros/cursos protegidos.
